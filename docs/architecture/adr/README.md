# Architecture Decision Records

Use an ADR for decisions that materially affect architecture, persistence, privacy, interoperability, evaluation or long-term maintenance.

## Naming

```text
NNNN-short-decision-title.md
```

## Template

```markdown
# ADR-NNNN — Title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context

What problem or constraint requires a decision?

## Decision

What are we choosing?

## Consequences

What becomes easier, harder or constrained?

## Alternatives considered

What credible alternatives were considered and why were they not chosen now?

## Revisit when

What evidence or change would justify revisiting the decision?
```

ADRs document decisions, not implementation tutorials.
